# UAE Rental Market Executive Dashboard | Power BI

## 📌 Project Overview
An interactive Real Estate Analytics Dashboard built using Microsoft Power BI to clean, model, and analyze large-scale property listings across the United Arab Emirates. Starting from 73,743 raw records, 720 duplicates were removed in Power Query to model 73,023 verified listings across 8 cities, exploring rental market trends, space yields, and price distributions through interactive visualizations, KPI cards, and cross-filtering slicers.


## 🎯 Objectives
- Analyze real estate inventory distribution across 8 major UAE emirates.
- Explore rental price variations by property type and geographic location.
- Track critical spatial metrics including square footage and price per square foot.
- Isolate extreme boundary market metrics (Maximum and Minimum rent thresholds).
- Present clear real estate investment and consumer trends through interactive dashboards.

## 🛠️ Tools & Technologies
- **Power BI** — Dashboard development, data modeling, and visualization
- **Power Query** — Data cleaning, deduplication, schema transformation, and row filtering
- **DAX (Data Analysis Expressions)** — Advanced business logic calculations and dynamic measures

## 📊 Dashboard Features
- **Top KPI Cards** — Displaying high-level market summaries (`Average Rent`, `Total Cities`, `Total Area`, `Max Rent`, and `Avg Rent SQFT`).
- **Dynamic Filter Slicers** — Left-sidebar control panel supporting interactive multi-select filtering for `City` and `House Type`.
- **Rent Share & Tier Analysis** — Proportional distribution breakdown (`Rent Share by Type`) alongside `Inventory Price Mix` segmented by `TIER` (`High`, `Medium`, `Low`) and furnishing status.
- **Volume Metrics Matrix** — Horizontal bar charts, city segmentation bars, and trend indicators mapping market segment density and location distributions.
- **Visual Grid Canvas** — Premium dark corporate blue theme with separated container cards for clean scannability.

## 🔍 Key Analysis Areas
1. Property distribution across 8 target emirates (`Abu Dhabi`, `Dubai`, `Sharjah`, `Ajman`, etc.).
2. Space utilization and rental pricing yields per square foot.
3. Pricing segmentation across residential layouts, tiers, and bedroom counts.
4. Comparative localized evaluation identifying premium vs. budget market zones.

## 📁 Project Files
- `UAE RENTAL MARKET EXECUTIVE DASHBOARD.pbix` — Master Power BI desktop application file housing the dashboard.
- `UAE RENTAL ANALYSIS.csv` — Source dataset containing 73,743 raw transaction rows (73,023 verified listings modeled after Power Query deduplication).
- `UAE_RENTAL_DASHBOARD.png` — Preview screenshot of the executive Power BI dashboard.

## 🚀 How to Use
1. Download the `.pbix` file from this repository.
2. Open it using Microsoft Power BI Desktop.
3. Click through the left-hand slicers and interactive charts to explore different UAE cities and real estate trends.
